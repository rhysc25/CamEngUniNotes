A state diagram is deterministic, the transition probabilities are either 0 or 1

A stochastic process $X_0,X_1,X_2,...,$ is a Markov chain if and only if for all times $i\geq 1$:
$P(X_{i+1}|X_0=j_0, X_1=j_1,...,X_i=i_i)=P(X_{i+1}|X_i=j_i)$
There are a set of random variables, indexed by time, each variable taking a value from the state-space

For any time $n$: $\textbf{x}^{(n)}=\textbf{x}^{(0)}\textbf{P}^{n}$ where $\textbf{P}$ is the transition matrix
Considering this transition matrix, we can say that $P(X_{i+n}=k|X_i=j)=(\textbf{P}^n)_{j,k}=P^n_{j,k}$

By some manipulation:
$P^n_{j,k}=\sum_lP^s_{j,l}P^{n-s}_{l,k} = \sum_lP(X_{i+n}=l|X_{i}=j)P(X_{i+n}=k|X_{i+s}=l)$

A limiting distribution is one which is converged to as $n$ increases
$\textbf{x}^{(\infty)}\textbf{P}=\textbf{x}^{(\infty)}$ - any distribution which satisfies this is a stationary distribution

A Markov chain is regular ergodic if there exists a unique stationary distribution which is the limit point for all initial distributions which puts a non zero probability on every element of the state space S

For an $n\times n$ transition matrix $\textbf{P}$ then:
1) $\lambda = 1$ is an eigenvalue of $\textbf{P}$
2) All eigenvalues satisfy $|\lambda|\leq 1$
