Scaling a sequence with a geometric sequence:

Time shift property of the DTFT:
Consider a sequence shifted by a delay d: $\{u_{k-d}\}$
If d is negative, it's an advance
$U'(\theta)=\sum_{k=-\infty}^{\infty}u_{k-d}e^{-jk\theta}$
Substitute $k' = k - d$, giving us $U'(\theta)=e^{-jd\theta}U(\theta)$

So time shift for DTFT results in multiplication by $e^{-jd\theta}$

For the z-transform it's a little more complicated.
If we have a delay, specifically for a signal which has values in negative indices, these must be included as they are moved into positive ones

$Z[\{u_{k-d}\}]=u_{-d}+u_{-(d-1)}z^{-1}+...+u_{-1}z^{-(d-1)}+z^{-d}U(z)$
Only for signals that are zero for negative time: 
$Z[\{u_{k-d}\}]=z^{-d}U(z)$
So the time delay operator is $z^{-1}$

If we have an advance, we are guaranteed to have signal values moved into negative indices, which must be removed from our transform

$Z[\{u_{k+d}\}]=z^{d}U(z)-z^du_0-z^{d-1}u_1 - ... - zu_{d-1}$

Convolution theorem reminder:

Initial value theorem:
$lim_{z\rightarrow \infty} U(z)=lim_{z\rightarrow \infty} (u_0 + \frac{u_1}{z}+\frac{u_2}{z^2}+...) = u_0$

Conjugate symmetry property:
For both transforms, it holds that:
$U(\overline{z})=\sum_{k=0}^{\infty}u_k \overline{z}^{-k}=\overline{\sum_{k=0}^{\infty}u_k z^{-k}}=\overline{U(z)}$

For the DFTF and hence on the unit circle, it satisfies that:
$|U(e^{-j\theta})|=|U(e^{j\theta})|$
$\angle U(e^{-j\theta})=-\angle U(e^{j\theta})$

ONLY the DTFT has reverse symmetry:
If $u_k= \overline{u}_k$ then the transform is purely real
