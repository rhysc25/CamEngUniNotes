Time shift property of the DTFT:
Consider a sequence shifted by a delay d: $\{u_{k-d}\}$
If d is negative, it's an advance
$U'(\theta)=\sum_{k=-\infty}^{\infty}u_{k-d}e^{-jk\theta}$
Substitute $k' = k - d$, giving us $U'(\theta)=e^{-jd\theta}U(\theta)$

So time shift for DTFT results in multiplication by $e^{-jd\theta}$

For the z-transform it's a little more complicated.
If we have a delay, specifically for a signal which has values in negative indices, these must be included as they are moved into positive ones

$Z[\{u_{k-d}\}]=u_{-d}+u_{-(d-1)}z^{-1}+...+u_{-1}z^{-(d-1)}+z^{-d}U(z)$
Only for signals that are zero for negative time: 
$Z[\{u_{k-d}\}]=z^{-d}U(z)$
So the time delay operator is $z^{-1}$

If we have an advance, we are guaranteed to have signal values moved into negative indices, which must be removed from our transform

$Z[\{u_{k+d}\}]=z^{d}U(z)-z^du_0-z^{d-1}u_1 - ... - zu_{d-1}$

BIBO Stability -
A discrete time system is stable if bounded inputs give bounded outputs
But more than that, for an input bounded by M, you must be able to say that ANY output is bounded by a SINGLE N

The following statements about G are equivalent:
1) G is stable
2) All of the roots $p_i$ of $a(z)$ satisfy $|p_i|<1$
3) $\sum_{k=0}^{\infty}|g_k|$ is finite

If A implies B implies C then A implies C
Also: If A implied B then not B implies not A

For proving (1) to (2) we need to consider arbitrary poles and also poles on the unit circle. Poles on the unit circle should give a sequence with a multiplicative factor k so must be unbounded.

Final Value Theorem:
Suppose that all the poles of $(z-1)Y(z)$ lie strictly inside the unit circle. 
This means that $Y(z)$ could have a pole at 1

$lim_{k\rightarrow \infty}y_k = lim_{z\rightarrow 1} (z-1)Y(z)$
But you must check the poles of $(z-1)Y(z)$ before applying it

Proof (similar to other proofs for z transforms) -
$Y(z)=\frac{\alpha_0}{1-z^{-1}}+\sum_i \frac{\alpha_i}{1-p_i z^{-1}}$ where $|p_i|<1$
This will work just as well with repeated poles, but is more tedious
By inverse z-transform:
$lim_{k\rightarrow \infty}y_k = lim_{k\rightarrow \infty}(\alpha_0 + \sum_i \alpha_i p_i^k) = \alpha_0$
And it's not hard to show that:
$lim_{z\rightarrow 1}(z-1)Y(z)=\alpha_0$, which proves it

The magnitude of the frequency response in dB is given by the sum of the log distances from the poles to $e^{j\theta}$
The phase response is given by the sum of the angles from the zeros to $e^{j\theta}$ minus the sum of the angles from the poles to $e^{j\theta}$

When $e^{j\theta}$ is close to a pole, the magnitude of the response rises (resonance). When it's close to a zero, it falls
