We learned to design a discrete-time filter from an analogue prototype, the resulting filters use feedback (IIR)

This lecture we design discrete-time filters directly from the ideal DTFT response, the resulting filters are feedforward only (FIR)

Ideal filter response for a lowpass is a sinc. However this is infinite and non causal, so we can't use it
![[Pasted image 20261111092318.png]]

$h_k$ is the non-causal impulse response of the ideal filter.
We want to shift it more into positive time, and truncate at $N+1$ samples (response goes from 0 to N)

$FIR: G(z) = \sum_{k=0}^N g_k z^{-k}$
$g_k = h_{k-N/2}$

Larger N is better as smaller samples discard so distortion reduced, but we still have a high first lobe and larger delay
![[Pasted image 20261111092638.png]]

Fourier series satisfies the periodic convolution property

$w_n = u_n v_n \rightarrow W(\theta) = \frac{1}{2\pi} \int_{-\pi}^{\pi}U(\psi)V(\theta - \psi) d\psi$

DTFT properties:
1) Discrete convolution in time = multiplication in frequency
2) Multiplication in time = periodic convolution in frequency

The effect of truncation - multiplication by a rectangular window
$g_k = \tilde{h}_k w_k$
$w_k$ = 1 for $0 \leq k \leq N$ and 0 otherwise
This is equivalent to a periodic convolution in the frequency 
![[Pasted image 20261111093526.png]]
The $e^{-j\frac{N\psi}{2}}$ is from the fact we have shifted the desired impulse response. Just this term as we're using the DTFT

DTFT of rectangular window:
$W(\theta) = \sum_{k=0}^N e^{-j\theta k} = e^{-j\frac{N\theta}{2}}\frac{\sin(\frac{\theta(N+1)}{2})}{\sin(\theta/2)} = e^{-j\frac{N\theta}{2}}D(\theta)$

$D(\theta)$ is the Dirichlet kernel
Often denoted $D_n(\theta)$ where $n = N/2$
This is a finite domain function
Looks very sinc like as:
$D(\theta)\approx (N+1)sinc(\frac{\theta(N+1)}{2})$
It turns out that the magnitude of a sidelobe doesn't depend on N
