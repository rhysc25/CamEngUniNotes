We learn how to map between the continuous Laplace domain and the discrete time z-domain

Why?
Covert analog designs to discrete time, say if we knew how to design an analog filter.
Or we're working on hybrid analog/digital systems. The analog component is included in the circuit via D/A and A/D converters

We need a digital model for the D/A, the physical system, and the A/D

How?
* Response matching - if it's responses are identical to identical inputs, then it must be the same
* Algebraic transformations to transform from the s domain to the z domain

Assume ideal DAC and ADC, unquantised, no clipping
Assume the physical system is a continuous-time linear shift and time-invariant system
This means that the overall sytem from $u_k$ to $y_k$ is linear and shift and time-invariant, so it must have a z transform

1) Measure input and output, find $Y(z)$ and $U(z)$, so you can find $G(z)$. In practice, measurements are noisy so you want to pick a $u_k$ that maximises SNR
2) Known physical system. You know the $G(s)$ for the physical system so you can do response matching

Example:
$u_k = 1$ for positive t. $u(t)=1$ for positive t, assuming a digital step becomes an analog step. 
$Y(s)= G(s)\frac{1}{s}$. $y_k = L^{-1}(\frac{G(s)}{s})$
$Z[y_k] = G(z)U(z) = Z[L^{-1}(\frac{G(s)}{s})]$
So $G(z) = \frac{z-1}{z}Z[L^{-1}(\frac{G(s)}{s})]$

Say, $G(s)$ was $\frac{1}{s+1}$, then $G(z) = 1 - \frac{z-1}{z-e^{-T}}$

Impulse invariance: A D/A converter cannot convert $\delta_k$ to $\delta(t)$

If we instead want ramp invariance:
$G(z) = \frac{(z-1)^2}{Tz}Z[L^{-1}(\frac{G_c(s)}{s^2})_{t=kT}]$

Response matching - 
Assume that the analog input $u(t)$ is the analog equivalent of the discrete-time input $u_k$
This is OK when the aim is to convert an analog design to a digital design. However if you want to model a whole system then the following expressions only apply if the DAC converts the discrete-time input signal to its analog equivalent

Impulse invariance - NOT valid for DACs:
$G(z) = Z[L^{-1}(G(s))_{t=kT}]$
When analog response above Nyquist frequency negligible, the digital filter frequency response closely approximates the continuous one, apart from a gain factor of $1/T$

This preserves stability

All 3 can be used to convert an analog design to a digital system. When used to model a physical system through a DAC/ADC, each method must be modified to ensure the analog input is teh signal generated by the DAC. If you modify in this way, they will have the same transfer function

DAC examples - 
Zero order hold -
$u(t) = u_k$ for $kT\leq t < (k+1)T$
Gives a staircase output

Mapping by algebraic transformation -
(Less preferred method)
Mapping between the s and z plane is $z\rightarrow e^{sT}$
For small T, the linear approximation is $z = 1+sT$, so $s = \frac{z-1}{T}$

Replace every occurrence of s in a continuous time system by $\frac{z-1}{T}$
Number of poles and zeros conserved

If we instead took a quadratic approximation of $e^{sT}$ we would end up increasing the number of poles and zeros

Common algebraic transforms:
* Euler's method or forward difference - $s = \frac{z-1}{T}$
* Backward difference - $s = \frac{1-z^{-1}}{T}$
* Bilinear (Tustin's) transformation - $s = \frac{2}{T}\frac{z-1}{z+1}$ or sometimes we drop the 2/T. The 2/T loses the physical correctness. This works as using the binomial theorem with s it becomes the quadratic expression of $e^{sT}$. It also still conserves poles and zeros

![[Pasted image 20261107110419.png]]
The shaded region is the set of points in the z-plane which is where the left half of the s-plane ends up after the transform

Backwards and Tustin when applied to a stable system give a stable system. This is not true for Euler's method

To prove that Tustins preserves stability:
Rearrange in terms of z. Write $sT/2 = \lambda + j\omega$. Find $|z|^2$ when $\lambda$ is 0 or less than 0

Frequency warping!
$s=\psi(z)=\frac{2}{T}\frac{z-1}{z+1}$
Analog filter $G_C(s)$. Digital filter: $G(z) = G_C(\psi(z))$
The normalised frequency response of the digital filter $(|\theta|\leq \pi)$ is given by:
$$G(e^{j\theta})=G_C(\psi(e^{j\theta}))$$
If ever we see $e^{j\theta}$ we should factor out a $e^{j\theta/2}$, giving us sinusoids
$G(e^{j\theta}) = G_C (j\frac{2}{T}\tan(\theta / 2))$
![[Pasted image 20261107112414.png]]
This shows how all the frequencies up to infinity are squeezed into $\pi$

Inverse relation: The frequency response of the analog filter at $\omega$ is mapped into the frequency response of the digital filter at $\theta = 2\arctan(\omega T /2)$
$\omega = \frac{2}{T}\tan(\theta / 2)\rightarrow \theta = 2\arctan(\omega T / 2)$
So $G_C(j\omega) = G(e^{j2\arctan(\omega T / 2)})$

Example:
If we have a first order lowpass filter with -3dB frequency of $1kHz$ and a sampling frequency of $8kHz$
The normalised digital cutoff frequency reads $\theta_c = 2\pi \frac{1000}{8000} = \pi /4$
Equivalent pre-warped analogue filter cutoff frequency with normalisation:
$\omega_c = \frac{2}{\pi}\tan(\theta_c / 2) = 16000\tan(\pi / 8). f_c = 1054.8Hz$

Without normalisation (more preferred):
$f_c = 0.066$ "$Hz$". This is actually some made up frequency range

Tustin-based filter design summay
* Normalise frequency $\theta = 2\pi f / f_s$
* Pre-warp $\omega = (2/T)\tan(\theta / 2)$. $2/T$ optional
* Design analogue prototype
* Apply Tustin's transform $s=(2/T)\frac{z-1}{z+1}$

Analog filter design
Different desired frequency response:
Lowpass, highpass, bandpass and bandstop

Butterworth filter:
N-th order lowpass $G_c(s)$
$G_c(s)G_c(-s) = \frac{1}{1+ (s/j\omega_c)^{2N}}$

$|G_c(j\omega)|^2 = \frac{1}{1+ (\omega/\omega_c)^{2N}}$

Standard transformations can transform lowpass prototype to other types. Assuming lowpass prototype with cutoff at 1:
Lowpass to lowpass: $s = \frac{s}{\omega_c}$ to make cutoff $\omega_c$
Lowpass to highpass: $s = \omega_c /s$
Lowpass to bandpass: $s = \frac{s^2 + \omega_l \omega_u}{s(\omega_u - \omega_l)}$
Lowpass to bandstop: $s = \frac{s(\omega_u - \omega_l)}{s^2 + \omega_l \omega_u}$
