In discrete time, signals are sequences $s_k$ indexed in $k$, systems are difference equations

In this course we will focus mainly but not exclusively on right-sided signals
$s = (s_m, s_{m+1}, s_{m+2},...)$. $s_k=0$ for $k<m$
A right-sided signals starting at zero is also called a semi-infinite sequence

This could be a sampled continuous signal, so $s_k=s(kT)$
When discussing a normalised frequency $\theta$, the true frequency can always be recovered as $f=\frac{\theta}{2\pi}f_s$

The definition of a Linear Time-Invariant (LTI) system L extends naturally from continuous to discrete time:
* Linear: $L(\alpha_1 u_k + \alpha_2 u_k')=\alpha_1 y_k + \alpha_2 y_k'$
* Time-invariant: $L(u_{k+m})=y_{k+m}$ for any $m$

The Kronecker Delta signal and response:
$\{\delta_k\}_{k\geq0}=\{1,0,0,...\}$ and $\delta_k=0$ for $k<0$

Every input signal $\{u_k\}$ to an LTIS can be written as 
$u_k=\sum_{n=-\infty}^{\infty}\delta_n u_{k-n}$ for every $k$

By the superposition principle, the output signal $\{y_k\}$ satisfies
$y_k=\sum_{n=\infty}^{\infty} g_n u_{k-n}$ for every $k$ where $\{g_k\}$ is the delta response which is equivalent to the difference equation in defining the LTIS
This is a discrete convolution, denoted $y=g*u$
Convolution is commutative

For a finite sequence $\{g_k\}_{0\leq k\leq l}$ then:
$$y_k = \sum_{n=0}^{min(l,k)} g_n u_{k-n}$$

z Transform -
The z transform is the discrete time equivalent of the Laplace transform
DTFT is the discrete-time equivalent of the Fourier transform

The convolution of finite signals is equivalent to the multiplication of polynomials
Discrete convolution of semi-infinite signals is equivalent to multiplication of power series
So all discrete transforms use this trick of converting signals to polynomials/power series

A formal power series uses a formal variable, where we never assign a value to the variable
$\frac{1}{1-D}=1+D+D^2+D^3+...$ Always holds in a formal power series
For non-formal, it is only true if $|D|<1$

In the z transform/DTFT, we do assign a value to the variable and hence it is a power series, as it allows us to analyse stability

For a signal $\{u_k\}$ the z transform is defined as:$$U(z)=\sum_{k=0}^{\infty}u_k z^{-k}$$
For example if $\{u_k\}$ was 1,2,3,4,5,0,0,0 then $U(z)=1+2z^{-1}+3z^{-2}+4z^{-3}+5z^{-5}$
If we have a geometric sequence $\{1,q,q^2,...\}$ then $U(z)=\frac{1}{1-qz^{-1}}=\frac{z}{z-q}$
This is only valid provided that $|z|>|q|$ so we are outside the radius $|q|$. 
This is the region of convergence (ROC) for the z transform. 

Following from this, if we have a unit step signal then $U(z)=\frac{z}{z-1}$

The ROC of the z transform is not strictly necessary to include, except when working with 2 sided z transform, where it can be the same for both sides so needs the ROC to distinguish, used for stochastic signal analysis. 
We will not use the two-sided z transform, instead using the DTFT

The Discrete-Time Fourier Transform (DTFT)
$U(\theta)=\sum_{k=-\infty}^{\infty}u_k e^{-jk\theta}$
If a signal is zero for negative values, this is the z transform with $z=e^{j\theta}$, so the z transform on the unit circle
