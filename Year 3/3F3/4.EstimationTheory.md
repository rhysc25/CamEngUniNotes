A model is a distribution = $p(\textbf{x} | \theta)$
$\textbf{x}$ = data [Latin]
$\theta$ = parameters [Greek]

In lectures 1-8: You tell me theta, I tell you x
Now we're doing: you tell me some data, I tell you theta

Parameters are usually under determined by data - not a unique set - no one right answer

You need to ask: How much do you trust $p(\textbf{x} | \theta)$ and how much do I trust the inferences

An estimator is a rule/function that turns data into an estimate of some quantity. Use hat when estimate: $\hat{\mu}$
E.g. sample mean

If just a number, it's a point estimate
We can also have interval estimator. $x\pm \epsilon$

Estimator example:
Maximum likelihood estimator (MLE)
$\hat{\theta} = argmax_{\theta} p(\textbf{x}|\theta)$.
Choose theta to maximise the likelihood of the data we received

If in three rolls we get 2 heads and a tails. Theta is the probability of heads. $p(x|\theta) = \theta^2 (1-\theta)$.
Take the gradient and set to zero to give you $\hat{\theta} = 2/3$
Even if the coin were fair, it's not possible to estimate theta = 1/2 from this data

Properties of estimators:
Ground truth value of parameter: $\theta_0$
$\hat{\theta}(\textbf{x}) =$ estimator for $\theta$

The BIAS of $\hat{\theta}$ is $E[\hat{\theta}(\textbf{x})]-\theta_0$
Unbiased if $E[\hat{\theta}(\textbf{x})]=\theta_0$
Unbiased doesn't always mean good

A family of estimators, $\hat{\theta}(x_1), \hat{\theta}(x_1,x_2),...$ is asymptotically unbiased if:
$\lim_{n\rightarrow \infty} E[\hat{\theta}(x_1,...,x_n)] = \theta_0$
![[Pasted image 20261111080302.png]]

We want the variance to tend to 0 as $n\rightarrow 0$
$Var[\hat{\theta}(\textbf{x})] = E[\hat{\theta}^2] - E[\hat{\theta}]^2$

A family of estimators is CONSISTENT if $\hat{\theta}$ converges to $\theta_0$.
$\lim_{n\rightarrow \infty} p(\hat{\theta}(x_1,...,x_n)) = \delta(\hat{\theta}-\theta_0)$
Sufficient condition: bias -> 0, variance -> 0

Prove MLE is consistent:
$\hat{\theta} = argmax_{\theta} p(\textbf{x}|\theta) = argmax_{\theta} \log(p(\textbf{x}|\theta))$ as logs are monotonic.
This is called the log-likelihood

For independent data:
$\log(\prod p(x_i|\theta)) = \sum \log p(x_i | \theta) = L(\theta)$

Find L and differentiate it and set to 0 for MLE
