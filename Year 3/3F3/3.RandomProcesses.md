A random process is a set of random variables $\{X_t:t\in T\}$ where T is an index set
In this course we will look at discrete time random processes. Each $X_t$ can be discrete, continuous or neither

E.g. we could have $U_t$ being $\pm 1$ both with probability 1/2, and $X_t = X_{t-1} + U_t$. This is a symmetric random walk

A random process can be defined by the conditional probability mass/density functions, so $f_{X_0}(x_0)$ all the way to $f_{X_n|X_{n-1},...,X_0}(x_n|x_{n-1},...,x_0)$

Markov Processes -
A discrete time random process has the Markov property if:$$f_{X_n|X_{n-1},...,X_0}(x_n|x_{n-1},...,x_0) = f_{X_n|X_{n-1}}(x_n|x_{n-1})$$
So clearly we only need to know the current state and dynamics to predict the next state. The system is memoryless

We usually assume Markov chains to be homogeneous, which is where: $f_{X_t|X_{t-1}}(x|y)=_{X_1|X_{0}}(x|y)$
Meaning: The transition probabilities don't change with time

The transition matrix Q for a homogeneous Markov chain is $Q_{ij} = P(X_{t+1} = j | X_t = i)$, which is a distribution in $j$
This means that $\sum_j Q_{ij} = 1$

For an initial condition $\textbf{p}^{(n)}=P(X_n)=\textbf{p}^{(0)}Q^n$

A discrete time random process is strictly stationary if:
$f_{X_0,...,X_k}(x_0,...,x_k)=f_{X_m,...,X_{m+k}}(x_m,...,x_{m+k})$ $\forall$ m and k

$(X_0,...,X_k)$ and $(X_m,...,X_{m+k})$ have the same distribution and cannot be distinguished. The statistical behaviour of the process does not change over time

For a Markov chain, stationarity if $\pi Q = \pi$. This is because our vectors are horizontal. A particular distribution is unchanged after applying the transition matrix

A Markov chain is irreducible if every state is reachable from every other. It has a unique stationary distribution $\pi Q = \pi$
The state i is recurrent if a chain that starts in state i will eventually return to i with probability 1. It is positive recurrent if the average time taken to return is finite. A state that is not recurrent is transient.

Finite, irreducible chains are positive recurrent

The period of state i is the largest divisor of $\{n:(Q^n)_{ii}>0\}$. If the period is 1 we say the state is aperiodic.

An irreducible aperiodic chain is one in which all states are reachable from one another and all states are aperiodic - If $(Q^n)_{ij}>0\forall i,j$. This is a "well behaved chain"
To check:
* $(Q^n)_{ij}>0$ for some n, for all i,j $\Rightarrow$ irreducible
* $(Q^{n+1})_{ij} = \sum_i Q_{ik}(Q^n)_{kj} = 0$. Can get from i to j in (n + 1) steps. $(Q^n)_{ii}>0$, $(Q^{n+1})_{ii}>0$, ... $\Rightarrow$ aperiodic

For an irreducible, aperiodic chain, either of the following two things must be true:
* $lim_{t\rightarrow \infty}P(X_t = j | X_0 = i) = \pi_j$ if positive recurrent
* $lim_{t\rightarrow \infty}P(X_C=j | X_0 = i) = 0$ diffuses to infinity

Ergodicity -
Roughly - you can look at one thing for a long time and learn everything you need to know about the system

$\textbf{X} = (X_1,X_2,...)$
A specific sample: $\textbf{x}=(x_1, x_2, ...)$
Let $f(x)$ be some function

Define the time average is $<f(\textbf{x})> = \lim_{T\rightarrow \infty} \frac{1}{T}\sum_{t=1}^Tf(x_t)$
This is a random variable which depends on the trajectory you're on.

A process is ergodic if $<f(\textbf{x})>$ (almost) always converges to $f^*$.
Doesn't matter which trajectory you're on. Time averages converge.

In general, $<f> \neq E[f]$
One is the time average (take on trajectory and average over time), the other is the ensemble average (average over trajectories)

Unless ergodic, where the long run time average converge to the expected value.
For an irreducible, aperiodic (+ve recurrent) Markov chain:
$\frac{1}{T}\sum_{t=1}^{T}f(X_t)\rightarrow \sum_i \pi_i f(i)$ or $<f>= E[f]$ so ergodic

This is a modelling consequence of irreducible and aperiodic. It's like assuming if you watch one stock for infinite time you know the expected behaviour of all stocks

It's a decent assumption for physical systems like one block of iron compared to all blocks of iron.

Can we weaken our assumption of stationarity?
Stationarity - every joint distribution of random variables is the same no matter where it is in time

The weaker version: Wide sense stationary (WSS)
* $E[X_t] = \mu$ for all t
* $E[X_t X_{t+k}] = E[X_0 X_k] < \infty$ for all t, k
This is how we prove it's wide sense stationary
Weaker than stationary if $E[X_t^2] < \infty$

If $X_t$ is WSS, then $X'_t = X_t - \mu$ is WSS
$E[X_t'] = 0$. We normally transform our variables to be mean 0

Define the autocorrelation function:
The general $R_X(t,s) = E[X_tX_s]$ however for a stationary process all that really matters is the gap between them, the variable $k$
$R_X(k) = E[X_0 X_k] = E[X_t X_{t+k}]$
Note: $E[X_t X_s] = R_X(s-t)$

Properties:
* Even function so $R_X(k) = R_X(-k)$
* $R_X(0) \geq 0$, as $R_X(0) = E[X_0^2] \geq 0$
* $|R_X(k)| \leq R_X(0)$. Maximum at origin, decays further away
Proof of that last one:
$E[(X_k - X_0)^2] = E[X_k^2 + X_0^2 - 2 X_0 X_k]$ = 2$R_X(0) - 2R_X(k) \geq 0$. $R_X(k) \leq R_x(0)$. Similarly if we expand $E[(X_k + X_0)^2]$ we can see that $R_X(k) \geq - R_X(0)$

White noise
A WSS process $W_t$ is white if $R_W(k) = \sigma^2$ for $k=0$ and 0 otherwise

e.g. Gaussian white noise $W_t ~ N(0, \sigma^2)$

Autoregressive process AR(p) -
Lets $W_t$ be white noise, $E[W_t] = 0$ and $R_W(k)=\delta_{0,k}\sigma_W^2$
Then $AR(p)$ is the process $(...,X_{-1}, X_0, X_1,...)$ where:
$X_t = \sum_{i=1}^p a_i X_{t-i} + W_t$
For constants $a_i$

$p$ is called the order, so AR(2) is second order

The most basic model, a good first model to test.

Moving average process MA(q) -
$X_t = \sum_{i = 1}^q b_i W_{t-i} + W_t$
Averaging the white noise at every time step
MA(q) is WSS

If the input to a LTI system is WSS, the output is also WSS. $Y_t = \sum_{k=-\infty}^{\infty}h_k X_{t-k}$
Linearity preserves the wide sense stationary property

Proof: 
i) $E[Y_t]= \sum_{k=-\infty}^{\infty}h_k E[X_{t-k}]$ which is constant, provided h is stable
ii) $E[Y_t Y_{t+s}]= \sum_{k,l} h_k h_l R_X(s-l+k)$ which is finite provided again that h is stable

Autoregressive Moving Average process ARMA(p,q) -
$X_t = \sum_{i=1}^pa_i X_{t-i}+\sum_{i=0}^q b_i W_{t-i}$
Averaging over previous values and previous and current noise
It can be represented as the output of an LTI system stimulated with white noise, so it is WSS

Proof: Premultiply be $z^t$ and sum over all t:
$\sum_{t= -\infty}^{\infty}z^t X_t = (\sum_{t= -\infty}^{\infty} z^t W_t)(\frac{\sum_{i=0}^{q}b_i z^i}{1-\sum_{i=1}^p a_i z^i})$
So $x = h * w$
Where $\sum_{t= -\infty}^{\infty} h_t z^t = (\frac{\sum_{i=0}^{q}b_i z^i}{1-\sum_{i=1}^p a_i z^i})$
Find the h which solves this, then can convolve this with the white noise
This shows that ARMA(p,q) is WSS

Power spectrum -
The power spectral density is the Fourier transform of $R_X(k)$
$$S_X(e^{i\omega})=\sum_{k=\infty}^{\infty}R_X(k)e^{-ik\omega}$$
The inversion is $R_X(k)=\frac{1}{2\pi}\int_{-\pi}^{\pi}S_X(e^{i\omega})e^{ik\omega}d\omega$

For real WSS $X_t$:
* $S_X$ is even
* $S_X$ is real
* $S_X$ is non-negative

The first two can be shown by taking the definition and writing the exponential in terms of sines and cosines, and its clear that $\sum_{k=-\infty}^{\infty}sin(k\omega) = 0$ so imaginary part is 0
All you have left is an even function multiplied by an even function

To show it's non negative you need to expand $R_X(k)$

If we consider $R_X(0)$ we see this is $\frac{1}{2\pi}\int_{-\pi}^{\pi}S_X(e^{i\omega})d\omega = \sigma_X^2 = E[X_t^2]$
So we can normalise by writing $\frac{S_X(e^{i\omega})}{R_X(0)}$, and this is essentially a probability distribution for which Fourier components are in the random signal

Only for WSS!!

For an LTI system: $S_Y(e^{i\omega})=S_X(e^{i\omega})|H(e^{i\omega})|^2$
Where H is the transfer function of the system
To find this H:
$Y_k = \sum_{k=-\infty}^{\infty}h_k X_{t-k}$, and $H(e^{i\omega}) = \sum_{t=-\infty}^{\infty}h_t e^{-it\omega}$

The power spectral density for white noise is $\sigma_W^2$

For an desired power spectrum, we can generate white noise and apply the transfer function $H(e^{i\omega})=(S_X(e^{i\omega}))^{1/2}$
To get a process with the same power spectrum

We can use this spectral density to generate $\omega$, so make $X_t' = A\sum \cos(\omega t + B)$, which has the same statistics as the original time series
