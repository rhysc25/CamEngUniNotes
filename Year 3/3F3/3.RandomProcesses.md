A random process is a set of random variables $\{X_t:t\in T\}$ where T is an index set
In this course we will look at discrete time random processes. Each $X_t$ can be discrete, continuous or neither

E.g. we could have $U_t$ being $\pm 1$ both with probability 1/2, and $X_t = X_{t-1} + U_t$. This is a symmetric random walk

A random process can be defined by the conditional probability mass/density functions, so $f_{X_0}(x_0)$ all the way to $f_{X_n|X_{n-1},...,X_0}(x_n|x_{n-1},...,x_0)$

Markov Processes -
A discrete time random process has the Markov property if:$$f_{X_n|X_{n-1},...,X_0}(x_n|x_{n-1},...,x_0) = f_{X_n|X_{n-1}}(x_n|x_{n-1})$$
So clearly we only need to know the current state and dynamics to predict the next state. The system is memoryless

We usually assume Markov chains to be homogeneous, which is where: $f_{X_t|X_{t-1}}(x|y)=_{X_1|X_{0}}(x|y)$
Meaning: The transition probabilities don't change with time

The transition matrix Q for a homogeneous Markov chain is $Q_{ij} = P(X_{t+1} = j | X_t = i)$, which is a distribution in $j$
This means that $\sum_j Q_{ij} = 1$

For an initial condition $\textbf{p}^{(n)}=P(X_n)=\textbf{p}^{(0)}Q^n$

A discrete time random process is strictly stationary if:
$f_{X_0,...,X_k}(x_0,...,x_k)=f_{X_m,...,X_{m+k}}(x_m,...,x_{m+k})$ $\forall$ m and k

$(X_0,...,X_k)$ and $(X_m,...,X_{m+k})$ have the same distribution and cannot be distinguished. The statistical behaviour of the process does not change over time

For a Markov chain, stationarity if $\pi Q = \pi$. A particular distribution is unchanged after applying the transition matrix

A Markov chain is irreducible if every state is reachable from every other. It has a unique stationary distribution $\pi Q = \pi$
The state i is recurrent if a chain that starts in state i will eventually return to i with probability 1. It is positive recurrent if the average time taken to return is finite. A state that is not recurrent is transient.

The period of state i is the largest divisor of $\{n:(Q^n)_{ii}>0\}$. If the period is 1 we say the state is aperiodic.
