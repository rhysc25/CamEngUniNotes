We want to consider variables that are infinite-dimensional, like trajectory

Probability space $(\Omega, P)$
$\Omega$ - sample space - set of all possible outcomes
An event E is a subset of the sample space $E\subseteq \Omega$

P - probability function
A function from events to the unit interval $P : \{E\} \rightarrow [0,1]$
1) $P(\Omega) = 1$ and $P(\emptyset)=0$
2) If $A_1$, $A_2$, ... are disjoint (no intersection) events, $A_i\cap A_j=\emptyset$ then
$$P(\cap_i A_i)=\sum_i P(A_i)$$
USE THESE TO PROVE SOMETHING IS A PROBABILITY FUNCTION

For finite $\Omega$ we can define the uniform probability function - $P(A)=\frac{|A|}{|\Omega|}$

$P(A\cup B) = P(A) + P(B) - P(A\cap B)$

$P(A|B)=\frac{P(A\cap B)}{P(B)}$
$P(A|B)$ is a probability function for A

In inference problems where D is the observed data and $\theta$ is something observed:
* $P(\theta | D)$ - the posterior probability for $\theta$
* $P(\theta)$ - the prior probability for $\theta$
* $P(D|\theta)$ - the likelihood
* $P(D)$ - the evidence

Law of total probability:
$B_i$ are disjoint 
$P(A)=\sum_i P(A|B_i)P(B_i)$

Bayes' rule: $P(A|B)=\frac{P(B|A)P(A)}{P(B)}$

Chain rule for probability:
$P(\cap_i A_i)=P(A_1)P(A_2|A_1)P(A_3|A_2 \cap A_1)...P(A_n | \cap_i A_i)$
This can be proven by induction

Independence -
$P(A\cap B) = P(A)P(B)$
$P(A|B) = P(A)$

Random Variables
Given a probability space $(\Omega,P)$, a rv is a function $X : \Omega \rightarrow \mathbb{R}$

A random variable is neither random now a variable, it is a deterministic function, the randomness comes from the outcome to which we apply that function
For $S\subseteq \mathbb{R}$: $P(X\in S) = P(\{w:X(w) \in S\})$
The left asks the probability that the random variable X takes a value in the set S
The right asks the probability of all the outcomes for which $X(w)$ exists in S

A function of an rv is an rv:
$Y=g(X) \Rightarrow Y(w) = g(X(w))$

CDF
$F_X(x)=P(X\leq x)$
If $x<y$ then $F(x)\leq F(y)$
F is right continuous, so if you approach $x=a$ from the right, you get $F(a)$

Discrete rvs
Discrete if it takes values in a countable subset of $\mathbb{R}$, and they have a probability mass function

Continuous rvs
Continuous if its distribution function can be written: $F(x) = \int_{-\infty}^x f(u) du$
The function $f(x)$ is a probability density function of the rv X

$f(x)=\frac{dF}{dx}$
$P(x\leq X\leq x+dx)=F(x+dx)-F(x)=f(x)dx$

The indicator function -
$I_A$ is 1 if $x\in A$ or 0 if $x \notin A$

Then $P(A)=\int_{-\infty}^{\infty}I_A(x)f(x)dx$
This is just saying $P(A)=\int_{A}f(x)dx$

Change of variables -
if $Y = g(X)$
If $g$ is invertible and increasing:
$f_Y(y)=f_X(g^{-1}(y))\frac{dg^{-1}}{dy}$

Prove by writing $x = g^{-1}(g(x))$ and chain rule

Normal distribution - $x$ ~ $N(\mu, \sigma^2)$
$$f(x)=\frac{1}{\sqrt{2\pi \sigma^2}}e^{-\frac{1}{2}\frac{(x-\mu)^2}{\sigma^2}}$$
Standard normal has $\mu = 0$ and $\sigma = 1$

i.i.d. - independent and identically distributed

Let's say we have a pdf $h(x)$. We can't generate samples from it. Plugging in x's gives us densities, and even then, how did we get those x's?

Generate samples from distribution with pdf $h(x)$
Inverse transform sampling -
1) Let U ~ Unif(0,1)
2) Return $H^{-1}(U)$
We can prove this be considering $X=H^{-1}(U)$
Then we can apply the change of variables formula
$f_X(x)=f_U(H(x))\frac{dH}{dx}= h(x)$
This works as $f_U(H(x))$ is 1 as $f_U(z) = 1/1 = 1$
However if the integration is hard, or the inverting isn't possible, this doesn't work

Rejection sampling -
Assume we can sample from distribution with pdf $g(x)$ and there exists a constant $g(x)>\frac{h(x)}{M}$
1) Sample U ~ Unif(0,1) and X from g
2) If U $\leq \frac{h(X)}{Mg(X)}$ return X, else return to step 1

Use an easy probability distribution $g(x)$ that covers the same bounds as $h(x)$, and that we can easily get samples from.
Scale $g(x)$ up so it completely covers $h(x)$, so $Mg(x)\geq h(x)$ for all $x$
Generate a sample from $g(x)$ and accept with probability $P=\frac{f(x)}{Mg(x)}$

Bayes rule shows that the distribution of the samples given that they are accepted is the target distribution.

Let the event that the sample is accepted be A. We want to find $P(X\leq x|A)$
A is then $U \leq \frac{h(X)}{Mg(X)}$

$a(x)$ is the probability of accepting a sample at x: $\frac{h(x)}{Mg(x)}$

We just need $P(A)$ and $P(X\leq x \cap A)$
$P(X\leq x \cap A) = \int_{-\infty}^x a(x)g(x)dx = \int_{-\infty}^x \frac{h(x)}{Mg(x)}g(x)=H(x)/M$

$P(A) = \int_{-\infty}^{\infty}a(x)g(x)dx=\frac{1}{M}$

Therefore $P(X\leq x|A) = H(x)$

This only holds if $h(x)$ is a normalised density. If not, let $Z=\int_{-\infty}^{\infty}h(x)dx$ so the correct result is $P(X\leq x|A) = H(x)/Z$
