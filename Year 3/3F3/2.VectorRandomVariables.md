Vector random variables -
Suppose we have two rvs X and Y. We can now consider the vector $(x,y)^T$
The join cdf of multivariate rv $\textbf{X}=(X_1,...,X_n)^T$ is the function $F_{\textbf{X}}(\textbf{x})=P(X_1\leq x_1, X_2 \leq x_2, ..., X_n \leq x_n)$

Some properties:
$lim_{y\rightarrow \infty}F_{\textbf{X}}((x,y)^T)=F_X(x)$
For discrete: pmf $p(\textbf{x})= P(\textbf{X}=\textbf{x})$
For continuous: pdf $f(\textbf{x}) = \frac{\partial^n F_\textbf{X}(\textbf{x})}{\partial x_1...\partial x_n}$

$X_1, X_2,..., X_n$ are independent if:
$F_{\textbf{X}}(\textbf{x})=F_{x_1}(x_1)...F_{x_n}(x_n)$. Is also the same in terms of the pdfs, which makes sense, as we can do $\frac{d}{dx}\frac{d}{dy}F_X(x)F_Y(y) = \frac{d}{dx}F_X(x)\frac{d}{dy}F_Y(y)$

Conditional Distributions
Discrete - $F_{Y|X}(y|x)=P(Y\leq y\mid X=x)$ 
Continuous - $F_{Y|X}(y|x)=\frac{\int_{-\infty}^{y} f_{X,Y}(x,v),dv}{f_X(x)}$
Has to be different as $P(X=x) = 0$ in the continuous case 

The conditional pmf/pdf is $\frac{f_{X,Y}(x,y)}{f_X(x)}$

Multivariate change of variables -
If $\textbf{Y}=g(\textbf{X})$ and g invertible
The Jacobian $J_{ij}=\frac{\partial x_i}{\partial y_j}$
$f_{\textbf{Y}}(\textbf{y})=f_{\textbf{x}}(g^{-1}(\textbf{y}))|det J(\textbf{y})|$

If we're going from i.i.d. multivariate normal to not i.i.d. $\textbf{y}=A \textbf{x}+\mu$, and $\textbf{X}=A^{-1}(\textbf{y}-\mu)$
Then $J_{ij} = (A^{-1})_{ij}$

$|det J|=|det A^{-1}|= \frac{1}{|det A|}$
$f_{\textbf{Y}}(\textbf{y})=\frac{1}{(2\pi)^{k/2}}\frac{1}{|det A|}e^{-\frac{1}{2}(A^{-1}(\textbf{y}-\mu))^T(A^{-1}(\textbf{y}-\mu))} = \frac{1}{(2\pi)^{k/2}}\frac{1}{|det A|}e^{-\frac{1}{2}(\textbf{y}-\mu)^T(A^{-1})^T(A^{-1})(\textbf{y}-\mu))}$  
Define $\Sigma = AA^T$

$f_{\textbf{Y}}(\textbf{y}) = \frac{1}{(2\pi)^{k/2}|det\Sigma|^{1/2}}e^{-\frac{1}{2}(\textbf{y}-\mu)^T\Sigma^{-1}(\textbf{y}-\mu)}$

Expectation -
The expected value of $\textbf{X}$:
Discrete = $\sum_{\textbf{x}}\textbf{x}p(\textbf{x})$
Continuous = $\int \textbf{x} f_{\textbf{x}} (\textbf{x}) d^n \textbf{x}$
Expectation is still linear

And for a function of it $E[g(\textbf{X})]=\int g(\textbf{x})f_{\textbf{x}}d^n \textbf{x}$

For a scalar:
kth moment of X is $\mu_k = E[X^k]$
The variance of X is $Var[X]=E[X^2]-E[X]^2$
The covariance is $Cov[X,Y]=E[XY] - E[X]E[Y]$
Uncorrelated if $E[XY]=E[X]E[Y]$

Independence implies uncorrelated
Uncorrelated does not imply independence
We can prove this by considering $E[XY]=\int \int xy f_{XY}(x,y)dxdy$

Covariance matrix of $\textbf{X}$
$\Sigma_{ij}=E[X_iX_j]-E[X_i]E[X_j]$
$\Sigma = E[\textbf{X}\textbf{X}^T] - E[\textbf{X}]E[\textbf{X}]^T$
$\Sigma$ is symmetric, and is positive semi-definite (eigenvalues are all greater than 0)
It has a "square root" $\Sigma = \textbf{S}\textbf{S}^T$. $\textbf{S}$ is not uniquely defined though, there are many possibilities

$E[Y|X]=\int y f_{Y|X}(y|x)dy$
The tower rule: $E[Y]=E[E[Y|X]]$
Important!!

The Generating Function -
$G_X(z)=E[z^X]=\int z^x f(x)dx$
Essentially like a Fourier transform of the pdf

For independent: $G_{X+Y}(z)=G_X(z)G_Y(z)$
$G_{aX}(z)=G_X(Z^a)$
$G_X(1)=E[1^x]=1$
$G'_X(1)=E[X]$
Proof: $\frac{d}{dz}E[z^x]=E[xz^{x-1}]$ by linearity. Can keep taking derivatives to get more moments of the distribution

$G'_X(0) = \frac{d}{dz}\sum_x P(x) z^x = P(1)$
In general the kth derivative of G at 0 gives $k!p(k)$

If we have continuous rvs, we use the characteristic function:
$\phi_X(t)=E[e^{itX}]=G_X(e^{it})$. This is just the Fourier transform

Inverse formula: $f(x)=\frac{1}{2\pi}\int_{-\infty}^{\infty}e^{-itx}\phi_X(t) dt$

Moments: $\phi_X^{(k)}(0)=i^k E[X^k]$
$\phi_{X+a}(t)=\phi_X(t)e^{iat}$
For X, Y independent: $\phi_{aX+bY}(t)=\phi_X(at)\phi_Y(bt)$

If X and Y have the same characteristic function, X and Y have the same distribution

Multivariate generating and characteristic functions -

Generating function: $G_{\mathbf{X}}(z) = E\left[\prod_i z_i^{X_i}\right]$
Characteristic function:$\varphi_{\mathbf{X}}(\mathbf{t}) = E\left[e^{i\mathbf{t}\cdot\mathbf{X}}\right] = E\left[\prod_i e^{it_i X_i}\right]$

Fact:
$$\varphi_{A\mathbf{X}+\mathbf{b}}(\mathbf{t}) = e^{i\mathbf{t}^T\mathbf{b}}\,\varphi_{\mathbf{X}}(A^T\mathbf{t})$$
Eg. for multivariate normal with mean $\boldsymbol{\mu}$, covariance $\boldsymbol{\Sigma}$
$$\varphi(\mathbf{t}) = e^{i\boldsymbol{\mu}^T\mathbf{t} - \frac{1}{2}\mathbf{t}^T\boldsymbol{\Sigma}\mathbf{t}}$$
The Law of Large Numbers states that as $n\rightarrow \infty$, the rv $\frac{1}{n}S_n$ approaches $\mu$
Central Limit Theorem: Assuming that $Var[X]$ is finite:
$$\frac{S_n-n\mu}{\sqrt{n\sigma^2}}$$
