Matrices:
A space: A vector space is a set which is closed under scalar multiplication and vector addition. I.e. if a and b are in the set, then ad + bc is also in the set.

Many vector spaces also have a dot product. 
$R^n$ - length n real vectors - $\textbf{x}_1 \cdot \textbf{x}_2 = \textbf{x}_1^T \textbf{x}_2$

$S\subset X$ is a subspace if it is also closed under scalar multiplication and vector addition

Range/column space = $\{Ax\}$
Kernel/null space = $\{x:Ax=0\}$
Left null space is orthogonal to the column space $\{x:A^Tx=0\}$
Row space is the column space of $A^T$. They are all the valid input vectors

Column rank = # of linearly independent columns
Row rank = # of linearly independent rows
Column rank = row rank

Lets call the rank r and the matrix pxq
The column space and the row space has dimension r 
The null space has dimensions q - r
The left null space has dimensions p - r
