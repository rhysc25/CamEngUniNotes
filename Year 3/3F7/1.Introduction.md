End-to-end communication system:
Compressor -> Transmitter -> Channel -> receiver -> Decompressor
Claude Shannon explored how you can model channels as probability distributions

We quantify information using entropy
$P_X(a)$ means the probability that a rv X takes the value a

Probability Review:
Random variable (rv) X: a function that maps outcome of experiment to value in set *X*
Discrete Random Variables:
Characterised by a probability mass function: $P_X(x)=Pr(X=x)$
Cumulative distribution function: 
$F_X(a)=Pr(X\leq a)=\sum_{x\leq a}P_X(x)$

Expectation of a function of an rv:
$E[g(X)]=\sum_a g(a)P_X(a)$

Jointly Distributed Discrete rvs $P_{XY}(x,y)$:
We can determine marginal distributions:
$P_X(x)=\sum_y P_{XY}(x,y)$
Conditional probability:
$P_{Y|X}(y|x) = \frac{P_{XY}(x,y)}{P_X(x)}$

More niche properties of jointly distributed rvs:
Product rule: $P_{XYZ}=P_{X}P_{Y|X}P_{Z|YX} = P_{Y}P_{X|Y}P_{Z|XY}$
This just comes from expanding the conditional probability formula into 3 variables
Sum rule:
$P_{XY}(x,y)=\sum_z P_{XYZ}(x,y,z)$

If instead we had continuous random variables $X,Y$ we would need a joint density function: $f_{XY}(x,y)$
$Pr(a\leq X\leq b, c\leq Y\leq d)= \int_{x=a}^b\int_{y=c}^d f_{XY}(x,y)dxdy$

Independence:
Discrete random variables are statistically independent if: $P_{X_1,...,X_n}(x_1,...,x_n)=P_{X_1}(x_1)...P_{X_n}(x_n)$
From this we can also say that they are independent if: $P_{X_i|\{X_j\}_{j\neq i}}=P_{X_i}$

If we want to know the uncertainty of an rv, we need entropy:
$H(x)=\sum_x P(x) log(\frac{1}{P(x)})$ bits
* log always refers to $log_2$ now
* If $P(x)=0$ then the limiting value is 0
* $H(x)$ can be written as $E[log\frac{1}{P(X)}]$

A Bernoulli rv is one which takes one of two possible outcomes, with a symmetric binary entropy function denoted as $H_2$

X can take values in *X*. The alphabet size of *X* is M
Properties of Entropy -
1) $H(X)\geq 0$
2) $H(X)\leq log M$
3) The equiprobable distribution $(1/M, ..., 1/M)$ has the maximum entropy of $log M$

Proof of (2):
Use the fact that $\ln(x)\leq(x-1)$, and get:
$H(X)-logM \leq \frac{1}{\ln(2)}\sum_x P(x)(\frac{1}{MP(x)}-1) = 0$

Joint and Conditional Entropy -
$H(X,Y)=\sum_{x,y}P_{XY}(x,y)\log\frac{1}{P_{XY}(x,y)}$
$H(Y|X)=\sum_{x,y}P_{XY}(x,y)\log\frac{1}{P_{Y|X}(y|x)}$
This can also be interpreted as the average uncertainty in Y given X:
$H(Y|X)=\sum_{x,y}P_{XY}(x,y)\log\frac{1}{P_{Y|X}(y|x)} = \sum_{x}P_{X}(x)\sum_y P_{Y|X}(y|x)\log\frac{1}{P_{Y|X}(y|x)}= \sum_{x}P_{X}(x)H(Y|X=x)$

$H(Y|X=x)$ is the uncertainty in Y conditioned on X=x, whereas $H(Y|X)$ is the average uncertainty in Y conditioned on the variable X

$H(X,Y) = H(X) + H(Y|X) = H(Y) + H(X|Y)$
The total uncertainty can be calculated by learning about one variable first, then measuring how much uncertainty remains about the other

Extending into many variables:
$\sum_{x_1,\ldots,x_n}  P_{X_1,\ldots,X_n}(x_1,\ldots,x_n) \log \frac{1}{P_{X_1,\ldots,X_n}(x_1,\ldots,x_n)}$

$H(X_1,X_2,\ldots,X_n) = H(X_1) + H(X_2 \mid X_1) + \cdots + H(X_n \mid X_{n-1},\ldots,X_1) = \sum_{i=1}^{n} H(X_i \mid X_{i-1},\ldots,X_1)$ 
Independence:
$H(X_1, X_2, ..., X_n)=\sum_{i=1}^n H(X_i)$
