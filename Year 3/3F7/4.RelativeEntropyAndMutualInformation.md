Relative entropy/ KL divergence between two pmfs P and Q is $$D(P||Q)=\sum_{x\in X}P(x)\log(\frac{P(x)}{Q(x)})$$
Where P and Q are defined on the same alphabet X
It is a measure of how difference the distributions are
It is not a true difference, $D(P||Q) \neq D(Q||P)$
Convention: $0\log(\frac{0}{q}) = 0$ and $p\log(\frac{p}{0})=\infty$

If both Bernoulli, $P=\text{Bern}(p)$ and $Q=\text{Bern}(q)$:  
$D(P||Q)=p\log\frac{p}{q}+(1-p)\log\frac{1-p}{1-q}$

Relative entropy is non-negative. It is zero if $P=Q$
Proof: Using $\ln(x) < x + 1$ again

Redundancy in source coding -
Suppose the true pmf is $P$, and the estimated pmf is $\hat{P}$
Create an optimal code for $\hat{P}$, what is our performance?

$L = \sum p_i \log \frac{1}{\hat{p_i}} = \sum p_i \log [\frac{1}{p_i}\times\frac{p_i}{\hat{p_i}}]$
$= H(P) + D(P||\hat{P})$ bits per symbol
So this is the overhead or penalty when assuming distribution. The penalty is the cross entropy

Choose $\hat{P}$ to minimise $max D(P||\hat{P})$, the worst case redundancy
With this choice: $R^* = min_{\hat{P}}max D(P||\hat{P})$
This is called the minimax redundancy - the best worst case redundancy

Hypothesis testing -
$H_0: X_1, ..., X_n$ ~ i.i.d. P
$H_1: X_1, ..., X_n$ ~ i.i.d. Q
Based on the data we have to decide which is true

A decision rule or a test is a function that maps the data to a binary decision $0$ for $H_0$, 1 for $H_1$
Types of errors:
1) Type 1 error/ false alarm: $H_0$ is true but the decision rule chooses $H_1$
2) Type 2 error/ miss detection: $H_1$ is true but the decision rule chooses $H_0$

We want to minimise both errors.
Given the data the likelihood ratio LR is defined as:
$\frac{Q(X_1, ..., X_n)}{P(X_1,...,X_n)}$. Normalised log-likelihood ratio LLR $\frac{1}{n}\log\frac{Q(X_1,...,X_n)}{P(X_1,...,X_n)}$

For some threshold T, choose $H_1$ if LR $\geq T$, or if the LLR $\geq t$
Both tests are equivalent by choosing $T=2^{nt}$

As t increases, the condition to choose $H_1$ becomes harder. Type 1 error probability decreased but type 2 increased.
The optimality of thresholding tests is in the following sense: If a thresholding test has probability of type 1 error $\alpha$ and probability of type 2 error $\beta$ then any other test that has type 1 prob $\leq \alpha$ must have type 2 prob $\geq \beta$

Under $H_1$: distribution Q, the log likelihood converges to $D(Q||P)$ in probability
Under $H_0$: distribution P, the log likelihood converges to $-D(P||Q)$ in probability

When the true distribution is Q, the likelihood of the data under the P distribution for large n is:
$P(X_1, ..., X_n)\approx Q(X_1, ..., X_n)2^{-nD(Q||P)}$

Mutual Information -
Two random variables X,Y with joint pmf $P_{XY}$
Mutual information: $I(X; Y) = H(X) - H(X|Y)$

$I(X; Y) = H(X) + H(Y) - H(X,Y)$. This shows that $I(X; Y) = I(Y; X)$
It is commutative. X says as much about Y as Y says about X

![[Pasted image 20261103101052.png]]
The two circle together represent $H(X,Y)$
$H(X)+H(Y)-\text{overlap} = H(X,Y)$

When X and Y independent, I = 0
When X = Y, I = $H(X)=H(Y)$
When $Y=f(X)$, $I = H(Y) = H(X) - H(X|Y)$

Can also write mutual information as:
$$I(X;Y) = D(P_{XY}||P_XP_Y)$$
It is the relative entropy between the joint pmf and the product of the marginals. How far from independence that X and Y are
Proof simple after writing out definitions of $H(X)$ and $H(X|Y)$

Property: $I(X; Y) \geq 0$
Implication $H(X|Y)\leq H(X)$. Knowing another variables can only reduce the average uncertainty in X

X input to channel, Y output. Amount of information you can transmit is the reduction in the uncertainty of the channel input X when you observe Y

Conditional mutual information:
$I(X; Y|Z) = H(X|Z) - H(X|Y,Z)$
Obeys a chain rule like entropy

Transmitter does two things - 
1) Coding to add redundancy to the data bits to protect against noise
2) Modulation to transform the coded bits into waveforms e.g. PSK, PAM, QAM

Coding - 
Repetition code -
If we repeat every bit k times, we have a data rate of 1/k, which goes to zero as the error rate goes to zero. The error probability is just the probability that more than half of the bits are flipped.
Shannon showed we can transmit bits with a strictly positive data rate with an arbitrarily small error probability

Discrete memoryless channel DMC -
A system consisting of input alphabet X, output alphabet Y, and a set of transition probabilities. $P_{Y|X}(b|a)=Pr(Y=b|X=a)$

Memoryless means that the channel acts independently on each input.
$Pr(Y_k=y|X_k =x, X_{k-1},...,X_1, Y_{k-1}, ..., Y_1) = P_{Y|X}(y|x)$

A DMC can be described by a transition probability matrix

DEC example -
Binary erasure channel (BEC):
With probability $\epsilon$, the bit is erased. Can model packet loss in networks. When the demodulator thinks the real-valued output symbol is too noisy, it can declare an erasure

Fun toy example - Noisy keyboard channel
Alphabet a through p. If you press a, you get a with probability 1/2 or b with probability 1/2. $P(Y=a| X=a) = P(Y=b|X=a)=1/2$

Could just eliminate half of your inputs. This is the maximum possible rate.
We've noiselessly conveyed 8 symbols per transmission so 3 bits/transmission
For a general DMC: We'll constrcut a set of input sequences which have non-intersecting sets of output sequences with high probability.

Channel capacity of  DMC -
$$C = max_{P_X} I(X; Y)$$
The max is determined over all input distributions $P_X$
Each $P_X$ gives a different joint distribution on $(X,Y)$ given by $P_XP_{Y|X}$
