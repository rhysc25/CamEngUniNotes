We use the channel n times to transmit k information bits. We can think of each sequence of k bits as indexing a message W.
So k bits give you $2^k$ messages

The rate R of the code is $R=k/n$ bits/transmission. The total number of messages is $2^k = 2^{nR}$

I need to convert each of the $2^k$ messages in terms of an input sequence of length n

An (n,k) channel code of rate R for the channel ($X,Y,P_{Y|X}$) consists of:
1) A set of messages: $2^k$ or $2^{nR}$ that is
2) An encoding function $X^n$ that assigns a codeword to each message. The set of codewords $X^n(1)$ to $X^n(2^{nR})$ is called the codebook
3) A decoding function g: $Y^n$ which produces a guess of the transmitted message for each received vector

Consider the binary symmetric channel:
For the ith bit: $Y_i = X_i \oplus E_i$ where $E_i$ is an error bit
$E_i$ are i.i.d ~ Bernoulli(0.1)
For large n, the number of ones in $(E_1,...,E_n) \approx 0.1n$ (By AEP). We expect to differ from the input by about 10% of bits

The set of highly likely sequences is gonna be the typical set, and the size of this is $2^{nH_2(0.1)}$
The high-probability set of typical $Y^n$ sequences for a given $X^n(1)$ is much smaller than $2^n$

Pick $X^n(2)$ whose typical set is far enough away from $X^n(1)$. They should be non-intersecting.

Number of distinct messages we can transmit = max number of disjoint sets each with size $\approx 2^{nH_2(0.1)}$ is roughly $\frac{2^n}{2^{nH_2(0.1)}}= 2^{n(1-H_2(0.1))}$
Therefore the rate $R\approx 1- H_2(0.1)$

The idea for a general DMC -
Fix an input pmf $P_X$. $P_{XY} = P_XP_{Y|X}$
$P_Y(y)= \sum_x P_X(x)P_{Y|X}(y|x)$

If we generate our codewords randomly, so $X^n(i)$ is generated i.i.d. ~$P_X$ then we will end up with disjoint sets

The size of typical $Y^n$ sets is $2^{nH(Y)}$
The size of a typical sequence when input $X^n$ is $2^{nH(Y|X)}$
Therefore number of disjoint typical sets you can have is $2^{n(H(Y)-H(Y|X))}$
So rate is $H(Y) - H(Y|X)$
