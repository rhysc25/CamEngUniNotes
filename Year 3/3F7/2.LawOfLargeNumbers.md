
Estimating tail probabilities -
We often want to bound the probability of rare/unlikely events, even if we don't know the distribution.
For example, maybe we just know that the average rate of occurence is 5/minute

The Markov inequality does this, and is for non-negative rvs and requires the mean
The Chebyshev inequality is for general rvs and requires mean and variance
Both give an UPPER bound on the probability

Markov Inequality, for any non-negative rv and any $a>0$:
$P(X\geq a) \leq \frac{E[X]}{a}$
This is useful only for $a>E[X]$

To prove this, we use an indicator function $1\{x\geq a\}$, that is 1 if $x\geq a$ and 0 if $x<a$

![[Pasted image 20261011115030.png]]

$\sum_{x\geq 0} xP(X=x) \geq \sum_{x\geq 0} a1\{x\geq a\}P(X=x)$
This can be written as $E[X]\geq aP(X\geq a)$

Chebyshev's Inequality:
We are bounding the tail probabilities of deviations around the mean $P(|X-E[X]|\geq a)$

$P(|X-E[X]|\geq a) \leq \frac{Var(X)}{a^2}$

Proof:
$P(|X-E[X]|^2\geq a^2)$ and let $Y=|X-E[X]|^2$
We can apply Markov's inequality to this to get:
$P(Y\geq a^2)\leq \frac{E[Y]}{a^2}$ as required

Weak Law of Large Numbers (WLLN)
Roughly speaking - Empirical average converges to the mean

Let $X_1, X_2, ...$ be a sequence of i.i.d random variables with finite mean $\mu$. Let $S_n = \frac{1}{n}\sum_{i=1}^nX_i$
Informal statement: $S_n \rightarrow \mu$ as $n \rightarrow \infty$
Formal statement: For any $\epsilon > 0, lim_{n\rightarrow \infty} P(|S_n - \mu|\geq \epsilon)=0$

$\epsilon$ can be arbitrarily small so we can get the sample mean arbitrarily close

This can be proven from Chebyshev's inequality:
$P(|S_n - \mu|\geq \epsilon) \leq \frac{Var(S_n)}{\epsilon^2}=\frac{\sigma^2}{n\epsilon^2}$
We call this the deviation probability
The factor of n appears with the variance of the sample means as it's a parameter calculated from the sample
This clearly converges to 0 as n tends to infinity

Much of information theory is a clever application of WLLN

Typical Sequences:
If $X_1,...,X_n$ are i.i.d. Bernoulli$(p)$ then for large n:
With high probability, the fraction of ones in the observed sequence will be close to $p$

The observed sequence will have probability close to $p^{np}(1-p)^{n(1-p)}$ as we expect $np$ 1s and $n(1-p)$ 0s

As any number a can be written as $2^{log(a)}$, then we can rearrange this as $2^{-nH_2(p)}$. A typical sequence is one whose probability is close to this value

Asymptotic Equipartition Property (AEP)
The AEP makes this precise for an i.i.d. discrete source, not just Bernoulli sequences:

If $X_1,X_2,...$ are i.i.d. then for any $\epsilon > 0$
$lim_{n\rightarrow \infty}Pr(|\frac{-1}{n}logP_X(X_1, X_2, ..., X_n)-H(X)|<\epsilon)=1$

As the sequence gets longer and longer, the average information per symbol gets closer and closer to the entropy $H(X)$

Proof:
Let $Y_i=-\log P_X (X_i)$. These are independent
The WLLN for $Y_i$ says:
$\lim_{n\rightarrow \infty}Pr(|\frac{1}{n}\sum_i Y_i - E[Y_1]|< \epsilon)=1$
This is pretty much there

The typical set $A_{\epsilon,n}$ has the property:
$2^{-n(H(X)+\epsilon)}\leq P(x_1,...,x_n)\leq 2^{-n(H(X)-\epsilon)}$
Sequences whose probability are concentrated around $2^{-nH(X)}$
Sequences belonging to this set are called $\epsilon$ - typical sequences

$X^n$ is the vector $X_1, X_2, ..., X_n$
Properties of the Typical Set
* As $n\rightarrow \infty: Pr(X^n\in A_{\epsilon,n})\rightarrow 1$
* The number of elements in the typical set $A_{\epsilon, n} \leq 2^{n(H(X)+\epsilon)}$ 
Proof:
1 = $\sum P(x^n) \geq \sum_{x^n \in A_{\epsilon, n}}P(x^n)\geq 2^{-n(H(X)+\epsilon)}|A_{\epsilon,n}|$
* For sufficiently large n: $|A_{\epsilon, n}|\geq (1-\epsilon)2^{n(H(X)-\epsilon)}$

SUMMARY:
* The sequence will by typical as n increases. It's probability will be close to $2^{-nH(X)}$
* The fraction of a in the sequence should be close to $P(a)$, and similarly for $b,c,...$
* The number of typical sequences is close to $2^{nH(X)}$
